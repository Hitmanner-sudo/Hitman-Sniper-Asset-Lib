# Hitman Sniper Asset Library

Textures and audio extracted from Hitman Sniper.

## 🎯 Browse the assets

**https://hitmanner-sudo.github.io/Hitman-Sniper-Asset-Lib/**

Search, preview, play and download every image and sound on your phone or PC.

## What's in the repo

| Folder | Contents |
| --- | --- |
| `public/images` | Textures, icons and UI art (PNG) |
| `public/audio` | Sound effects, voice lines and music (OGG, WAV) |
| `ExportedProject` | The exported Unity project |
| `AuxiliaryFiles` | Game assemblies and the path ID map |
| `site` | Source for the asset browser ([how it works](site/README.md)) |

The browser rebuilds automatically on every push to `main`, so new files in `public/` show up there within a couple of minutes.
